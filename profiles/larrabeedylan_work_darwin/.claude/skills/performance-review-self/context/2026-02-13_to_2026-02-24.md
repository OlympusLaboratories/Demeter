- **Channel:** platform-infra-team
- **People involved:** Dylan, Mark, Travis Thompson
- Dylan spent several hours debugging why Cloud Trace → BigQuery sink silently dropped all spans after initial working state. Opened a GCP support ticket (with Mark's help getting permissions). Dylan deployed a custom OTEL collector using the `googlecloud` exporter as a workaround ([tlaloc-env !1975](https://gitlab.com/gridmatic/tlaloc-env/-/merge_requests/1975)).

- **Channel:** platform-infra-team, prod
- **People involved:** Dylan, Marshall, Mark
- Dylan added pod labels to Buildkite steps for per-step resource monitoring (PLAT-1163). Initially set kube-state-metrics `--metric-labels-allowlist=pods=[*]` which caused alert spam by scraping all ephemeral pod labels. Fixed by scoping to `pods=[buildkite-step,buildkite-pipeline]`.

- Dylan built a Grafana dashboard for per-step resource monitoring, designed to inform right-sizing of Buildkite resource requests.
